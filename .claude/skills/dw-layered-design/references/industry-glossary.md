# 行业场景参考

当用户来自不熟悉的业务领域时，查阅此文件了解该行业的核心维度、业务过程和常见指标，避免设计出"通用但脱离业务"的数仓。

## 电商

### 核心业务过程
浏览 → 加购 → 下单 → 支付 → 发货 → 签收 → 退货/退款 → 评价

### 常见维度
| 维度 | SCD | 说明 |
|------|-----|------|
| 用户 | Type 2 | 等级、会员状态会变化 |
| 商品/SKU | Type 1 | 价格、状态会更新 |
| 类目 | 静态 | 商品分类层级 |
| 店铺 | Type 1 | 店铺评分会变化 |
| 地区 | 静态 | 省-市-区三级 |
| 渠道 | 静态 | App/Web/小程序/线下 |
| 时间 | 静态 | 日期维度表 |

### 核心指标
| 指标 | 计算逻辑 | 注意事项 |
|------|---------|---------|
| GMV | SUM(order_amount) 所有下单金额 | 含未支付、已退款 |
| 实际成交额 | SUM(pay_amount) 支付成功金额 | 扣除退款 |
| 支付转化率 | pay_count / order_count | DWS 存分子分母 |
| 客单价 | pay_amount / pay_user_count | |
| 复购率 | 有≥2笔订单的用户数 / 总用户数 | 需定义时间窗口 |
| 退货率 | refund_count / pay_count | |
| 留存率 | 第N日活跃用户 / 注册用户 | N日留存矩阵 |

## 制造业（汽车/装备/电子）

### 核心业务过程
原料入库 → 生产排程 → 上线生产 → 工位装配 → 质检 → 下线入库 → 售后索赔

### 常见维度
| 维度 | SCD | 说明 |
|------|-----|------|
| 产品/车型 | Type 1 | 车型配置可能调整 |
| 工厂/产线/工位 | 静态 | 产线布局相对固定 |
| 供应商 | Type 1 | 供应商评级会变 |
| 零部件 | Type 1 | BOM 可能变更 |
| 缺陷编码 | 静态 | 标准缺陷分类 |
| 经销商 | Type 1 | |
| 员工/工人 | Type 2 | 岗位、技能等级变化 |

### 核心指标
| 指标 | 计算逻辑 | 注意事项 |
|------|---------|---------|
| IPTV（千台故障率） | 故障数 / 产量 × 1000 | 分月度/累计 |
| OEE（设备综合效率） | 可用率 × 性能率 × 良品率 | 三个分量分别存 |
| 良品率/直通率 | 合格数 / 总检数 | 分工位/产线 |
| MTBF（平均故障间隔） | 总运行时间 / 故障次数 | 设备维度 |
| 供应商 PPM | 不良件数 / 供件总数 × 1,000,000 | |
| 单车追溯 | 以 VIN 为主键的宽表 | 关联生产+质检+售后 |

## 在线教育

### 核心业务过程
注册 → 浏览课程 → 购买 → 观看视频 → 提交作业 → 获得证书

### 常见维度
| 维度 | SCD | 说明 |
|------|-----|------|
| 用户/学员 | Type 2 | 学习等级、VIP状态变化 |
| 课程 | Type 1 | 价格、状态会更新 |
| 章节/课时 | Type 1 | 视频时长可能调整 |
| 讲师 | Type 1 | |
| 课程分类 | 静态 | |

### 核心指标
| 指标 | 计算逻辑 | 注意事项 |
|------|---------|---------|
| 完课率 | 已完课人数 / 购课人数 | 需定义"完课"标准（如完成80%章节） |
| 课程完成进度 | 已完成章节数 / 总章节数 | 用户×课程粒度 |
| ARPU | 总营收 / 活跃用户数 | |
| 学习时长 | SUM(video_duration) | 去除暂停/倍速影响 |
| 课均播放率 | 播放时长 / 视频总时长 | |
| 退款率 | 退款订单数 / 总订单数 | |

## 医疗/医院

### 核心业务过程
挂号 → 就诊 → 检查检验 → 开方 → 取药/治疗 → 出院 → 随访

### 常见维度
| 维度 | SCD | 说明 |
|------|-----|------|
| 患者 | Type 2 | 诊断、病情会变化 |
| 科室 | 静态 | |
| 医生 | Type 2 | 职称会变化 |
| 药品 | Type 1 | 价格调整 |
| 病种/诊断(ICD-10) | 静态 | 国际疾病分类标准 |
| 手术/操作(ICD-9-CM) | 静态 | |

### 核心指标
| 指标 | 计算逻辑 | 注意事项 |
|------|---------|---------|
| 门诊量 | COUNT(visit_id) | 分科室/日/月 |
| 床位使用率 | 实际占用床日 / 开放总床日 | |
| 平均住院日 | SUM(住院天数) / 出院人次 | |
| 药占比 | 药品收入 / 总收入 | 医院绩效关键指标 |
| DRG 组权重 | 按 DRG 分组的费用权重 | 医保支付相关 |
| 医生绩效 | 工作量 × 难度系数 | 按科室有不同公式 |

## 金融/银行

### 核心业务过程
开户 → 存取款 → 转账 → 贷款申请 → 审批 → 放款 → 还款 → 逾期

### 常见维度
| 维度 | SCD | 说明 |
|------|-----|------|
| 客户 | Type 2 | 风险等级、资产等级变化 |
| 账户 | Type 2 | 状态变化（冻结/注销等） |
| 产品 | Type 1 | 利率、费率调整 |
| 机构/网点 | Type 1 | |
| 渠道 | 静态 | 柜面/手机银行/网银/ATM |
| 币种 | 静态 | |

### 核心指标
| 指标 | 计算逻辑 | 注意事项 |
|------|---------|---------|
| AUM（管理资产规模） | 存款 + 理财 + 基金 + ... | 日终时点余额 |
| 不良贷款率 | 不良贷款余额 / 贷款总余额 | 五级分类标准 |
| 存贷比 | 贷款余额 / 存款余额 | |
| 日均存款 | SUM(日余额) / 天数 | 不等于月末余额 |
| MAU | 当月有登录/交易的客户数 | 去重 |
| 逾期率 | 逾期贷款 / 发放贷款 | 分30/60/90天 |

## 物流/供应链

### 核心业务过程
下单 → 揽收 → 运输（多段） → 转运/中转 → 末端配送 → 签收 → 异常处理

### 常见维度
| 维度 | SCD | 说明 |
|------|-----|------|
| 寄件人/收件人 | Type 1 | |
| 网点/站点 | Type 1 | 状态可能变化 |
| 线路 | Type 1 | 起始-终点 |
| 区域 | 静态 | 省-市-区 |
| 运输方式 | 静态 | 陆运/空运/铁运 |
| 异常类型 | 静态 | 丢失/破损/延误 |

### 核心指标
| 指标 | 计算逻辑 | 注意事项 |
|------|---------|---------|
| 时效达成率 | 准时签收数 / 总单量 | 需定义时效标准（如24h/48h） |
| 签收率 | 签收数 / 发件数 | |
| 异常率 | 异常件数 / 总单量 | |
| 单票成本 | 总运营成本 / 总单量 | 分段计算 |
| 装载率 | 实际装载量 / 车辆容量 | |
| 末端配送效率 | 日均配送单量 / 快递员数 | |
